# Dados sintéticos

`inf_diario_demo.csv` é uma fixture criada para o projeto, não um recorte da CVM.
Os CNPJs são fictícios e não identificam investimentos reais. O arquivo tem um mês de
informes artificiais, duas subclasses com o mesmo CNPJ e uma terceira identidade.
Há cota ausente, fluxo ausente e um dia de semana omitido de propósito.
Feriados não foram aplicados ao calendário sintético.
